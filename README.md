# Sistema de Vendas - SQL

Scripts SQL para gerenciar um **sistema de vendas**, com cadastro de clientes, produtos e pedidos.  
Inclui **dados de exemplo**, consultas para análise e verificação de inconsistências, e uma **versão normalizada** do banco para otimização e integridade referencial.  
Ideal para estudo de **modelagem de banco de dados** e operações básicas de vendas.
